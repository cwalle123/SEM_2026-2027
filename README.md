# Welcome to the SEM Minor Project Github repo!

### Aim of the project

This project forms part of the final research project for the TUDelft Modern Physics minor and aims to improve characterisation of Scanning Electron Microscopes (SEM)
electron probes, allowing for quick diagonis and correction of possible beams aberrations.

In order to do so, a multi-layer Convolutional Neural Network is being developed to map the an extracted PSF to the corresponding coefficients that form it. This CNN is trained using an unsupervised
approach simulating PSFs with known coefficients and training from them.
